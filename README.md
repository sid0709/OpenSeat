# OpenSeat

Permissioned help marketplace: hunters open sealed jobs and invite bidders.

## Start here

Use Node.js 24 and npm 11.13.0. Run `npm ci` from the root, then
`npm run dev --workspace @openseat/web`.

- [Contribution workflow](docs/CONTRIBUTING.md)
- [Coding style](docs/CODING_STYLE.md)
- [Testing standards](docs/TESTING.md)
- [Monorepo architecture](docs/ADRs/0001-monorepo-tooling.md)
- [Releases](docs/RELEASING.md) and [staging](docs/STAGING.md)
- [Junior contribution rules](docs/JUNIOR_CONTRIBUTIONS.md)
- [Infrastructure audit](docs/INFRASTRUCTURE_AUDIT.md)
- [Required GitHub settings](docs/REPOSITORY_SETTINGS.md)

Run `npm run lint`, `npm run format:check`, `npm run typecheck`,
`npm run test:coverage`, `npm run build`, and `npm run e2e` before review.
